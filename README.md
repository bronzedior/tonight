# Tonight

An iOS and watchOS application that helps users prevent alcohol intoxication by monitoring physiological changes using Apple Watch sensors.

## Features

- Apple Watch Monitoring
- Risk Level Detection
- Personalized Baseline
- Emergency Contact
- Drinking History

## Tech Stack

- SwiftUI
- watchOS
- HealthKit
- CoreMotion
- WatchConnectivity
- XcodeGen
